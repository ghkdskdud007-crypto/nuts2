# 🌰 특수학교 1학년 견과류 포장하기 어플리케이션

특수학교 1학년 학생들의 직업 전환교육, 소근육 발달, 일과 훈련을 위해 개발된 **아이패드 가로(Landscape) 화면 최적화 인터랙티브 웹 애플리케이션**입니다.

---

## 🌟 주요 기능 및 페이지 구성

### 1. 첫번째 페이지: 견과류 알아보기 & 이름 맞추기
- **견과류 카드 학습**: **아몬드, 호두, 피칸, 캐슈넛**의 선명하고 친근한 일러스트 제공. 카드를 터치하면 견과류 이름이 크고 또렷하게 표시되며 한국어 음성(TTS)으로 특징을 읽어줍니다.
- **견과류 이름 맞추기 퀴즈 게임**: 질문과 힌트를 듣고 4가지 견과류 중 맞는 것을 고르면 칭찬 효과음(딩동댕!), 별점 스티커, 축하 폭죽이 제공됩니다.

### 2. 두번째 페이지: 활동 1 - 견과류 포장 연습하기 (수준별 3단계 학습)
포장 목표: **아몬드 4개 ➜ 호두 4개 ➜ 피칸 2개 ➜ 캐슈넛 2개** (총 12개) 순서대로 포장 봉투에 담기
- **1단계 (순서 드래그 모드)**: 정해진 순서대로 봉투에 드래그하여 담기.
  - *순서가 틀릴 경우*: 친절한 안내 메시지와 음성 피드백 출력 (예: *"아몬드 1개를 넣어주세요!"*, *"피칸 1개를 넣을 차례입니다!"*).
- **2단계 (숫자 도움 모드)**: 위 활동이 어려운 학생들을 위해 봉투 슬롯과 견과류에 **①~⑫번 숫자 표기와 번호 안내**를 제공하여 번호대로 쉽게 드래그할 수 있습니다.
- **3단계 (원터치 쏙 담기 모드)**: 소근육 조작이 힘든 학생들을 위해 **터치(클릭)만 해도** 퐁당 효과음과 함께 봉투 안으로 쏙 들어가는 초간단 모드입니다.
- **[확인하기] 버튼**: 담은 개수를 채점하여 **100점 점수판과 "참 잘했어요💮" 칭찬 스티커 팝업**을 띄웁니다.

### 3. 세번째 페이지: 활동 2 - 실제 견과류 포장하기 (직업훈련 작업지시 & 카메라 검사)
- **1단계: 순서대로 포장하기 (아몬드 ➜ 호두 ➜ 피칸 ➜ 캐슈넛)**
  - **작업 지시문 표시**: *"아몬드 4개, 호두 4개, 피칸 2개, 캐슈넛 2개를 포장 봉투에 순서대로 담고 실링기로 포장을 하세요."*
  - **단계별 버튼 터치 이동**: 상단의 **[아몬드 4개]**, **[호두 4개]**, **[피칸 2개]**, **[캐슈넛 2개]**, **[실링기 포장]** 버튼을 직접 터치하여 원하는 포장 및 검사 단계로 자유롭게 즉시 이동할 수 있습니다.
  - **단계별 카메라 비추기 검사**: 각 견과류 검사 후 합격/불합격 판정 및 예시 견본 제공.
  - **실링기 밀봉 단계**: 캐슈넛까지 담으면 *"실링기로 포장을 한 후 포장검수대로 가세요"* 음성과 함께 실링기 누르기 인터랙션 실행.
  - **[🔄 처음부터 다시하기] 버튼**: 언제든지 아몬드 4개 1단계로 돌아가 다시 포장 실습을 반복할 수 있습니다.
- **2단계: 분류된 견과류 모아서 포장하기 (순서가 어려운 학생들을 위한 쉬운 모드)**
  - **작업 지시문 표시**: *"작업지시서: 분류된 견과류를 봉투에 담고 포장하세요."*
  - 미리 분류된 견과류 12개(아몬드 4, 호두 4, 피칸 2, 캐슈넛 2)를 한 번에 봉투에 담아 카메라 화면에 비추고 **[📸 분류된 견과류 검사하기]** 버튼으로 검사합니다.
  - 합격 시 실링기 단계로 바로 이동할 수 있습니다.

### 4. 네번째 페이지: 활동 3 - 품질 검수 및 포장 라벨지 붙이기
- **최종 품질 검수**: 포장한 완성 봉투를 비춰 견과류가 개수대로 담겨있는지 검사.
  - 합격 시: *"딩동댕 합격입니다! 라벨지를 붙여주세요"* 안내 음성 출력.
- **[🔄 품질 검수 다시하기] 버튼**: 검수 결과를 초기화하여 학생들이 원하는 만큼 검수 활동을 여러 번 반복 연습할 수 있습니다.
- **라벨 스티커 붙이기**: 학생이 직접 **[하루 건강 견과]** 라벨 스티커를 봉투 중앙에 착! 붙이는 성취감 만점 피날레.
- **포장 달인 상장**: 모든 과정을 수료한 학생에게 이름이 적힌 칭찬 수료증 수여 및 인쇄 지원.

## 📱 아이패드(iPad) 사용 팁
- 아이패드 가로 방향(Landscape)에 맞춰 가로 1024px~1366px 해상도에 최적화되어 있습니다.
- 사파리(Safari)에서 상단 주소창을 숨기기 위해 우측 상단 `⛶ 전체화면` 버튼을 누르거나, **[홈 화면에 추가]**를 하면 전체화면 앱(PWA 방식)처럼 더욱 몰입감 있게 사용할 수 있습니다.
- 모든 버튼과 드래그 요소는 터치 제스처와 소근육 발달에 맞춘 48px 이상의 대형 크기입니다.

## 🚀 깃허브 에듀케이션 (GitHub Education) & GitHub Pages 배포 방법

학생과 선생님이 언제 어디서든 아이패드 링크 하나로 접속할 수 있도록 GitHub Pages에 배포하는 방법입니다.

1. **GitHub 로그인 및 새 저장소 생성**:
   - [GitHub.com](https://github.com)에 로그인합니다.
   - 우측 상단 `+` 버튼 ➜ `New repository` 클릭.
   - 저장소 이름(Repository name) 입력: 예) `nuts-packing-app`
   - **Public**으로 설정하고 `Create repository` 클릭.

2. **파일 업로드**:
   - 생성된 저장소 페이지에서 `uploading an existing file` 링크 클릭.
   - 현재 폴더의 3가지 핵심 파일(`index.html`, `style.css`, `app.js`)을 드래그하여 업로드합니다.
   - 하단의 `Commit changes` 클릭.

3. **GitHub Pages 활성화**:
   - 저장소 상단 메뉴의 **Settings(설정)** 클릭.
   - 좌측 사이드바에서 **Pages** 메뉴 클릭.
   - **Build and deployment** ➜ **Branch**를 `main`(또는 `master`)으로 선택하고 폴더는 `/ (root)` 선택 후 **Save** 클릭.

4. **웹 주소 접속**:
   - 약 1~2분 후 상단에 배포된 URL이 표시됩니다.
   - 예: `https://[깃허브아이디].github.io/nuts-packing-app/`
   - 이 링크를 아이패드의 사파리(Safari) 브라우저에서 열면 바로 수업에 활용할 수 있습니다!
